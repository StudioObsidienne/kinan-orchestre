# Code of conduct / Code de conduite

This project adopts the Contributor Covenant, version 2.1: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: respect people, direct criticism at the work and not at individuals, no harassment.

Ce projet adopte le Contributor Covenant, version 2.1 : https://www.contributor-covenant.org/version/2/1/code_of_conduct/

En bref : respect des personnes, critiques portées sur le travail et non sur les gens, aucun harcèlement.

## Reporting / Signalement
Report a problem through the repository's issues (`https://github.com/StudioObsidienne/kinan-orchestre`) or, for a confidential report, through a private GitHub Security Advisory. Reports are handled confidentially.

Signalez un problème via les issues du dépôt (`https://github.com/StudioObsidienne/kinan-orchestre`) ou, pour un signalement confidentiel, via un advisory privé GitHub. Les signalements sont traités de façon confidentielle.
